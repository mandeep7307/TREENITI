# 🌳 TREENITI (त्रिनिति) - Green Gamified Plantation & Earning Platform

> **डिजिटल हरियाली से असली पर्यावरण क्रांति**  
> Complete Web & Mobile App Dual-Experience Platform built for Environmental Awareness, Tree Care Gamification, Multi-tier MLM Referral Earnings, and Verified Real-World Tree Plantation.

---

## 🌟 All Implemented Features (User Requirements 100% Covered)

### 1. 📱 User Account & Security System
* **Mobile OTP Login**: Instant OTP generation (`1234` for regular users, `9999` for Super Admin) with 1-click quick demo buttons.
* **User Profile**: Avatar emoji selector, tree naming, stats, phone number, and referral identity.
* **Bilingual Language Switcher (हिंदी / English)**: 1-click toggle dynamically translating the entire app UI.
* **Dual App & Web Experience**:
  * **Mobile App Mode 📱**: Pixel-perfect native phone frame with bottom navigation bar, haptic audio effects, and touch controls.
  * **Desktop Web Mode 💻**: Responsive layout for wide laptop and monitor displays.

### 2. 🎮 Two Interactive Games
1. **Game 1 - Tree Water & Care**:
   * **Water Tree 💧**: Interactive watering drops animation, Web Audio synthesizer splash sounds, +15 coins reward.
   * **Organic Fertilizer & Care 🌿 (खाद और कीटनाशक दवा)**: Bio-nutrition boost, +25 coins reward.
   * **Daily Growth Limit**: Hard-capped at **4% daily growth** to prevent exploitation.
2. **Game 2 - Shake Tree (पेड़ हिलाओ)**:
   * Periodic cooldown timer (15 minutes).
   * 10-second interactive mini-game: tree shakes with rustle sound effects, sweet fruits (🍎 / 🍏) shake loose and fall down, user taps falling fruits to collect them into the basket.
   * Awards harvested fruits + bonus coins!

### 3. 🌱 Virtual Tree System & 7 Growth Levels
* **Digital Seed Planting & Tree Naming**: Custom names like "मेरा कल्पवृक्ष".
* **7 Dynamic Growth Levels**:
  * **Level 1 – Seed (बीज)**: Digital seed planted in soil.
  * **Level 2 – Sprout (अंकुर)**: Tender dual-leaf sapling + coins reward.
  * **Level 3 – Plant (पौधा)**: Growing plant with daily streak bonuses.
  * **Level 4 – Growing Plant (बढ़ता पौधा)**: Forest birds 🕊️ & butterflies 🦋 animation unlocked.
  * **Level 5 – Young Tree (युवा वृक्ष)**: Blooming flowers 🌸 & floral canopy.
  * **Level 6 – Mature Tree (फलदार वृक्ष)**: Hanging apples & fruits.
  * **Level 7 – Mighty Kalpavriksha (महावृक्ष)**: Golden glowing aura & bountiful infinite harvest.
* **Tree Mood System**:
  * `Happy 😊`, `Waiting 🥺`, `Sad 😢`, `Excited 🤩`
* **Tree Talking Messages & Random Thank You**:
  * Dynamic speech bubble: *"धन्यवाद! आपने मुझे पानी दिया, मैं आपको शुद्ध हवा दूंगा! 🍃"*.
  * Admin customizable messages.

### 4. 🍎 Fruit Economy System
* Fruits collected from the Shake Game or Mature trees appear in the Fruit Inventory.
* **Sell Fruits**: 1-click convert fruits to coins (1 Fruit = 50 Coins = ₹0.50).

### 5. 🪙 Coin Reward System (100 Coins = ₹1)
* **Daily Check-in**: Streak-based login bonus (+50 coins).
* **3-Hour Routine Claim**: Oxygen reward claimable every 3 hours (+35 coins).
* **Lucky Spin Wheel 🛞**: Interactive rotating wheel with prizes up to 500 Coins jackpot!
* **Social Media Follow Tasks**:
  * 📺 YouTube (+150 Coins)
  * 📘 Facebook (+100 Coins)
  * 📸 Instagram (+100 Coins)
  * 🐦 Twitter / X (+50 Coins)
  * 💬 WhatsApp Channel (+50 Coins)
  * ✈️ Telegram Channel (+50 Coins)
* **Daily Missions**: Water tree 2x, read article, play shake game, spin wheel.

### 6. 📚 Article & Knowledge System (Anti-Cheat)
* Environmental education articles.
* **Reading Time Tracker**: Requires minimum 70% active reading time.
* **Active Tab Detection**: Uses HTML5 Visibility API — pauses timer if user switches tabs.
* **Scroll-to-Bottom Verification**: Ensures user actually reads through the content.
* Daily cap of 5 articles to prevent botting.

### 7. 👥 Multi-Level Referral System (MLM A - B - C)
* **Total Milestone Reward per Friend = ₹21**:
  * Friend registers: **₹5**
  * Active for 3 days: **₹6**
  * Active for 7 days: **₹10**
* **Lifetime Multi-Tier Passive Commission**:
  * **Level 1 (Direct Invites)**: **5% lifetime commission** on all earnings of friend B.
  * **Level 2 (Sub Invites)**: **2% lifetime commission** on all earnings of friend C.
* **My Team Dashboard**: Tabbed view of Level 1 and Level 2 team members, phone numbers, and earnings.

### 8. 📸 Real Plantation Live Tracking & Verification
* Real-world photo tracking milestones: **Day 1 (Planting) + Day 7 + Day 15 + Day 30**.
* User snaps/uploads photos of their real sapling.
* Review dashboard for Super Admin to verify photos and credit +100 to +500 coins.

### 9. 📜 Tree Certificate Auto-Generator
* Official ornate green & gold certificate with Royal Afforestation Seals.
* Auto-generated with **User Name**, **Tree ID** (e.g. `TRN-00001-2026`), **Tree Name**, **Plantation Date**, and **QR verification code**.
* 1-Click Print / Save as Image and Share on Social Media / WhatsApp.

### 10. 💰 Wallet & UPI Withdrawal System
* Real-time ledger of Coins, Cash Balance (₹), Referral Earnings, and Total Withdrawn.
* **Minimum Withdrawal**: **₹10**.
* **Payment Methods**: Direct UPI ID (Google Pay, PhonePe, Paytm, BHIM).
* Real-time status tracking: Pending, Approved (with Bank UTR number), Rejected (with auto-refund).

### 11. 📢 सूचना बोर्ड (Live Running Ticker)
* Broadcasts real-time community activity:
  * *"रवि ने आज 2 नए पेड़ लगाए और ₹15 कमाए! 🌱"*
  * *"अमित ने ₹50 का UPI विड्रॉल प्राप्त किया! 💰"*

### 12. 👑 Super Admin Panel
* Complete administrative control over every part of the platform:
  * **Dashboard Overview**: Metrics on users, trees, pending payouts, pending photos, coins distributed.
  * **User Management**: Search by phone/name, Ban / Unban accounts, view balances.
  * **Withdrawal Approvals**: Enter Bank UTR number and approve, or reject with note.
  * **Plantation Reviews**: Inspect Day 1/7/15/30 plant photos, approve (+150 coins) or reject.
  * **Article Management**: Publish new Hindi/English environmental articles or delete existing.
  * **Notice Board Management**: Add live running ticker announcements.
  * **Economy Settings**: Configure coin rate (100 coins = ₹1), min withdrawal (₹10), daily growth limit (4%).

## 🚀 How to Run the Project

### Option 1: Unified Production Mode (Web & App on Single Port)
```bash
# In the project root directory:
npm start
```
Open **[http://localhost:5000](http://localhost:5000)** in your browser!

### Option 2: Development Mode (Vite Hot-Reload)
```bash
# Terminal 1: Backend server
cd server
node server.js

# Terminal 2: Frontend Vite
cd client
npm run dev
```
Open **[http://localhost:5173](http://localhost:5173)** in your browser.
